# 潜入深渊 · Deep-Sea Dive

一次滚动驱动的深海漫游：从海平面直达马里亚纳海沟**挑战者深渊（10,935 米）**，
沿途经过五大水层，认识每个深度的真实世界——自由潜水纪录、抹香鲸猎场、泰坦尼克号、
蛟龙号、最深的鱼……直到人类四次载人触底的编年史。

灵感来自 neal.fun 的滚动式科普叙事，是「AI 导游太阳系」主力项目的练手作。

## 运行

```bash
npm install          # 已装好可跳过
npm run dev          # → http://localhost:5174
npm run build        # 产出 dist/ 纯静态文件，可直接部署到任意静态托管
```

要求 Node ≥ 20.19（Vite 7）。本机用 `nvm use 22.22.0`。

## 技术栈

- **React 19**（函数组件 + Hooks，ref 作为 prop 的新写法）
- **Vite 7**
- 零 UI 库、零动画库：水体/海雪/鱼群/水母全部是手写 Canvas 2D，卡片动画用 IntersectionObserver + CSS transition

## 架构要点（值得学的两个模式）

1. **滚动深度 ≠ React 状态**：60fps 的滚动深度如果放进 useState 会引发每帧全树重渲染。
   这里用 `App.jsx` 里的唯一 rAF 循环 + `useImperativeHandle` 命令式刷新画布和仪表盘，
   React 只负责渲染静态结构。
2. **数据驱动世界**：所有深度内容在 `src/data.js` 里声明（水层、里程碑、温度剖面、颜色剖面），
   加一条新卡片只需加一行数据，不用碰组件。

## 目录

```
src/
  data.js               # 全部深度/生物/剖面数据（改这里就能加内容）
  App.jsx               # rAF 主循环 + 页面骨架
  components/
    OceanCanvas.jsx     # Canvas 水体：颜色渐变/光柱/海雪/鱼群/发光水母
    World.jsx           # 水层横幅 + 里程碑卡片 + 深度标尺 + 触底档案
    Hud.jsx             # 右侧深度仪表盘（深度/压力/水温/光照/水层）
    Intro.jsx           # 开场屏
    Silhouette.jsx      # 手绘 SVG 剪影（鲸/乌贼/泰坦尼克）
  styles.css
```

## 数据说明

深度与水层依据公开海洋学资料整理（数值为常见引用值，如挑战者深渊 ≈10,935 m、
海洋平均深度 ≈3,688 m、已知最深鱼类 8,178 m 等）；温度剖面为近似值。
后续可接入真实数据源（GEBCO 海深剖面、GBIF 生物分布）做成"真数据版"。
